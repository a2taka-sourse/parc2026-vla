# PARC2026 VLA fine-tuning notes

ロボット操作のシミュレーション（LIBERO 系）で、Vision-Language-Action モデルを LoRA で適応させた記録です。
Physical AI Robot Challenge 2026（PARC2026）の予選 Track 1 で公式スコア **0.36363** を記録し、本選に進みました。

このリポジトリには、学習・マージ・評価に使った Colab ノートブックと、試した手法の結果を置いています。学習済みの重みは置いていません（下記「ライセンス」）。

## 結果の要約

計19回提出し、スコアを大きく上げたのはバックボーンの交換の1回でした。

| # | 変更 | スコア |
| --- | --- | ---: |
| 1 | 既定値 `n_action_steps`=50 のまま | 0.0 |
| 3 | 画像の180度回転を修正、`n_action_steps`=10 | 0.06545 |
| 5–6 | SmolVLA に LoRA、誤差拡散平滑化 α=0.5 | 0.13178 |
| 7–12 | 画像拡張・タスク40種・重複排除・平滑化の強化・中央値投票 | 0.069〜0.124 |
| **13** | **SmolVLA（0.5B）→ π0.5（3.7B）に交換** | **0.36363** |
| 14–19 | 推論ステップ数・再学習・実行長ゲート・LoRA差分の縮小 | 0.241〜0.311 |

分かったこと：

- **天井はモデルの側にあった。** 手元の未知の摂動24件で、ベース重みと自作 LoRA の結果が24件中23件で一致しました。学習側の工夫では挙動がほぼ動かないと判断し、容量の大きいモデルに乗り換えました。
- **推論時に外から足した制御規則は、5方式すべてで悪化した。** 行動のがたつき（ジャーク）はチャンクの継ぎ目に集中していました。継ぎ目を滑らかにする方式（最平滑の選択、補間、クロスフェード、RTC、学習済みの実行長ゲート）は、どれも新しい観測への反応を遅らせ、成功率を下げました。
- **LoRA の差分は効いていた。** マージ後の重みとベースの差分を75%に縮めると、0.36363 → 0.31137 に下がりました。手元の評価器では検出できなかった寄与を、重みの側から確かめた実験です。
- **スコア0の2回は、どちらも性能と無関係だった。** `n_action_steps`=50（約2.5秒の盲目実行）と、`transformers` の版を固定し忘れたことによる例外です。例外がスコアに出ず、性能不足と見分けがつかない点に注意が要ります。

## 構成（最高スコア）

- ベース: `lerobot/pi05_libero_finetuned_v044`（π0.5、PaliGemma + action expert、約3.7B、bfloat16）
- 学習: action expert のみ LoRA（r=16, α=16）、6,000 step、batch 8、学習率 1e-4→1e-5（コサイン）、画像拡張なし
- データ: `lerobot/libero_plus` から4タスク×60エピソード（独自の収集・生成はなし）
- 推論: `chunk_size`=50 のうち `n_action_steps`=10 を実行して再観測、誤差拡散平滑化 α=0.5
- 環境: Google Colab（A100）、LeRobot 0.6.0 + peft
